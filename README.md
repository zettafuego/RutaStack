# RutaStack

App local para aprender este stack como una sola máquina. El dominio de ejemplo es **Planea**: frentes, toneladas y un agente que resume la semana.

Cubre Python 3.12, FastAPI, Next.js 16, React 19, Server Actions, Tailwind, shadcn, Vercel, el AI SDK, MCP, el harness de Eve, bases vectoriales, Supabase/Postgres, un warehouse agnóstico, Vercel Sandboxes, Anthropic, AgentMail, Grafana, Turborepo, pnpm, GitHub Actions y un preview aislado por pull request (pantalla, API y rama de base).

No despliega nada de eso. No pide claves. El progreso queda en `localStorage` de este navegador.

## Abrir

Doble clic en `start.bat`, o:

```bat
py -3 -m http.server 8765 --bind 127.0.0.1
```

Luego abre http://127.0.0.1:8765

Los nombres de API están tomados de la documentación vigente hacia noviembre de 2026. La firma exacta cambia. El dueño de cada pieza no.
